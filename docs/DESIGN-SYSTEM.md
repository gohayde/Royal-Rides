# Design System

## Brand Feel

Royal Rides Car Rental must feel:
Clean
Affordable
Trustworthy
Family friendly
Modern
Bright
Simple
Reliable
Easy to book

It must not feel:
Dark
Super luxury
Exotic car focused
Aggressive
Overdesigned
Generic
Cheap in a low quality way

## Colour Palette

Primary CTA / Accent:
#DA5259

Text / Authority:
#111827

Background / Clean Base:
#F8F8F6

Supporting colours:
White: #FFFFFF
Muted Text: #6B7280
Soft Border: #E5E7EB
Soft Accent Background: #FDEDEF
Warm Neutral: #FFF7F6

## Colour Usage

Use #DA5259 for:
Primary CTA buttons
WhatsApp style CTAs
Active states
Small icon accents
Important highlights

Use #111827 for:
Headings
Primary body emphasis
Navigation
Trust messaging

Use #F8F8F6 for:
Main background
Soft section backgrounds
Clean base panels

Use white for:
Cards
Header
Booking panels
Form fields

Use muted grey for:
Supporting copy
Metadata
Card descriptions
Secondary labels

## Typography

Headings:
Plus Jakarta Sans

Body:
Inter

Heading rules:
Use strong clean headings.
Use clear hierarchy.
Avoid overly thin heading weights.
Keep headings readable on mobile.

Body rules:
Use Inter for readability.
Use comfortable line height.
Keep paragraphs concise.
Use short blocks of copy.

## Layout Rules

Use:
Generous spacing
Clear containers
Responsive grids
Soft rounded cards
Subtle shadows
Clean white panels
Clear CTA hierarchy

Avoid:
Crowded layouts
Dark hero sections
Hard shadows
Overlapping too many elements
Tiny mobile text
Unclear booking forms

## Button Rules

Primary button:
Accent background #DA5259
White text
Rounded
Clear hover state
Strong visual priority

Secondary button:
White or transparent background
Dark text
Soft border
Clear hover state

CTA text:
WhatsApp Now
Request Availability
Browse Cars
Check Availability
View Category

## Card Rules

Cards should feel:
Clean
Trustworthy
Soft
Practical
Easy to scan

Use:
White backgrounds
Soft borders
Rounded corners
Consistent padding
Clear titles
Short descriptions
Small icon or image area

## Image Direction

Use practical car rental visuals when assets exist.
Use light backgrounds.
Use clean car cards.
Use family friendly and travel friendly mood.
Do not use dark supercar studio visuals.
Do not make every section look luxury.

## Responsive Rules

Mobile:
CTAs must be obvious.
Header must be easy to use.
Booking form must stack cleanly.
Cards must be easy to read.
No horizontal overflow.

Tablet:
Use two column grids where useful.
Keep spacing balanced.

Desktop:
Use strong hero layout.
Use multi column cards.
Keep max width controlled.
Do not stretch text too wide.
