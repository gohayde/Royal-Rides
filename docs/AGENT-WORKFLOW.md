# Agent Workflow

## Purpose

This document tells AI coding agents how to work inside this repository.

## Before Any Work

1. Read `AGENTS.md`.
2. Read the relevant docs in `/docs`.
3. Inspect the existing project files.
4. Identify the current source structure.
5. Identify existing routes, components, styles, and assets.
6. Do not edit until the repo structure is understood.

## Repo Safety

Do not delete unrelated files.
Do not rewrite unrelated files.
Do not rename folders unless necessary.
Do not change package manager unless explicitly required.
Do not switch frameworks.
Do not add a backend.
Do not add database setup.
Do not add authentication.
Do not add CMS.
Do not add payment processing.

## Website Build Process

When the user asks to build the website:

1. Inspect the project.
2. Confirm it is Vite React TypeScript Tailwind.
3. Use the homepage sitemap from `AGENTS.md`.
4. Create or update components as needed.
5. Keep code clean and responsive.
6. Use specific Royal Rides content.
7. Add WhatsApp and request availability CTAs.
8. Keep style clean, affordable, trustworthy, and family friendly.
9. Test locally when possible.
10. Summarize the work.
